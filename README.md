# Homebrew tap for Keyway

```bash
brew install --cask arminsameti/tap/keyway
```

Or add the tap first: `brew tap arminsameti/tap`, then `brew install --cask keyway`.

[Keyway](https://github.com/arminsameti/Keyway) is a native macOS client for Xray, sing-box, V2Ray core, Mihomo and Tor.
The cask installs the universal release from GitHub and checks it against its SHA-256. A workflow here follows new
Keyway releases, so `brew upgrade --cask keyway` keeps you current.
